# Gyubi Park Portfolio

개인 작업을 검색하고 분류하기 위한 정적 포트폴리오 아카이브입니다.

## GitHub Pages

이 저장소는 루트의 `index.html`을 그대로 GitHub Pages에 게시하도록 구성되어 있습니다.

## 프로젝트 수정

- 초기 데이터: `projects.js`
- 검색, 필터, 편집 및 JSON 백업 기능: `app.js`
- 화면 디자인: `styles.css`
- 실제 프로젝트 이미지: `assets/`

사이트의 **Manage** 버튼에서 수정한 데이터는 현재 브라우저의 로컬 저장소에만 저장됩니다. 다른 기기에서도 같은 데이터를 쓰려면 JSON을 내보내거나 `projects.js`를 직접 수정해 저장소에 반영하세요.
